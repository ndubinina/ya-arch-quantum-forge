## Задание 1. Исследование моделей и инфраструктуры

#### LLM модель

Выбрана локальная Llama 3 (Hugging Face).
Почему: Нужна локальная LLM для работы с чувствительными данными на разных языках
Почему не выбраны другие модели: YandexGPT ориентирован на кириллицу, OpenAI не имеет on-prem реализации

#### Модель эмбеддингов

Выбран локальный HuggingFace HuggingFace.
Почему: данные не выходят за пределы серверов компании. Поддержана мультиязычность, что актуально для международной компании.
Почему не облачные решения: в данных есть чувствительная информация, облачные решения не подходят

#### Векторная база

Выбран ChromaDB.
Почему: упрощает старт для разработке (актуально для MVP), проще работать с разными типами документов.
Почему не FAISS: требует больше ресурсов специалистов на внедрение и поддержку

#### Серверная конфигурация
